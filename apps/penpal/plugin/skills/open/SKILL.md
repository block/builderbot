# Opening Documents in Penpal

To open a document in the Penpal desktop app for human review, run the CLI
command via Bash:

```
penpal open <path>...
```

This launches the Penpal app if needed, adds the file to the project, and
navigates to it. You can pass multiple paths to open several files at once.

Use this when you've written or updated a document (research, plan, design doc,
etc.) and want a human to review it and leave comments.
